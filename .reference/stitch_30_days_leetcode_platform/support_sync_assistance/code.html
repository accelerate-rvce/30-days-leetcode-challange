What is the verification frequency?

The automatic daemon crawls all registered cohort profiles every 30 minutes, or within 90 seconds if a manual ping is triggered.

Can I link multiple LeetCode handles?

No. Each collegiate participant is tied to a single authenticated LeetCode handle to preserve competitive integrity on the leaderboard.

How are timezones computed?

All sprint daily resets correspond to midnight UTC. Ensure code commits on LeetCode are registered before this threshold.
